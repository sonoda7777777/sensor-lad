# sensor_lab プロジェクト指示

## .inoファイルの生成・編集時のルール

`.ino`ファイル（Arduinoスケッチ）を生成または編集する際は、以下を必ず守ること。

- **C++の記法を守る**
  - Arduino方言に頼らず、C++として正しい構文・スタイルで記述する
- **不変の変数には`const`を付与する**
  - プログラム実行中に値が変わらない変数は必ず`const`（または`constexpr`）を付ける
  - ピン番号・しきい値・設定値などは特に対象
- **型は値の範囲に応じて適切に選ぶ**
  - 安易に`int`を使わず、値の範囲・符号の有無・メモリサイズを考慮する
  - 例: ピン番号や0〜255の値 → `uint8_t` / 0〜65535 → `uint16_t` / カウンタで負値を取らない → `unsigned`系
  - 浮動小数点が必要な場合、AVR系では`double`は`float`と同じ精度なので`float`で十分なことが多い
