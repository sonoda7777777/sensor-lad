このスキルを実行した際、以下の手順に沿って作業を行う

1. `microcontrollers/`と`sensors/`直下に`README.md`が存在するかを確認
2. `README.md`が存在しない場合、以下のフォーマットに沿って`README.md`を作成。この時、名前は、ディレクトリ名から推測する。

## センサREADMEのフォーマット

各センサのREADMEは以下の形式で記載する。

```markdown
# {センサ名}

| 項目 | 内容 |
|------|------|
| 型番 | |
| メーカー | |
| 個数 | |
| 計測対象 | |

## 画像
![表面](images/front.jpg)

## メモ
```

## マイコンREADMEのフォーマット

各マイコンのREADMEは以下の形式で記載する。

```markdown
# {マイコン名}

| 項目 | 内容 |
|------|------|
| 型番 | |
| メーカー | |
| 個数 | |
| クロック | |
| フラッシュ | |
| RAM | |
| インターフェース | |

## 画像
![表面](images/front.jpg)

## メモ
```

3. 型番やメーカーといった情報は名前から調べて埋めてください。個数は、`images/`直下の画像ファイル数を埋めてください。
4. 2で追加したセンサまたはマイコンを`sensor_lab/README.md`のセンサ一覧またはマイコン一覧に追加
5. 画像ファイル名はfront.jpgに更新する。
